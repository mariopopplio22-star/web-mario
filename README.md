# Estructura del proyecto "web-mario"

- css: Contiene los estilos 
- images: Contiene las imagenes que se usarán para esta web 
- js: Contiene los archivos JavaScript 

# Tecnologías a usar

- HTML
- CSS
- IA Geminis para la generación de codigo css

# Uso del repositorio 

- Crear un repositorio en Github
- En la terminal del proyecto hacer los commits "Actualizaciones" a lo largo de los días para modificar el proyecto hasta estar listo
- Usar clone para clonar el repositorio 
- Usar pull para traer los cambios hechos en otro equipo
